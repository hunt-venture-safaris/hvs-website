# TrustBar

A full-width band of credentials: Govt. Licence No. 2087, since 1989, and the three ranges. It answers "is this outfitter legal and established" before the hunter asks.

**Provide:** up to five items, each a figure or name and a short label. Default set: "No. 2087 / Govt. licence", "1989 / Established", "Karakoram", "Himalaya", "Hindu Kush" (label "Range").

- `hvs-trust` on `field-deep`, 1px `brass-rule` top and bottom, `radius-0`, full bleed. Figures `data-lg` in `ink` with tabular figures; labels `eyebrow` in `brass`; `line` dividers between items.
- Place directly under the hero, and again above the footer on long pages if needed.
- Wraps to two per row on phones.

Don't: add unverified claims (success rates, awards, membership logos) until the client supplies proof; animate the numbers.
